Subtext settings

Your key is stored locally in this browser and is only sent to OpenAI when you trigger a suggestion.

Create one at platform.openai.com → API keys. Use a key with chat access.

Then: open chatgpt.com, type a rough prompt, and click the small Improve chip that appears above the message box — or press Alt+Shift+I. Esc closes the suggestion panel, Ctrl+Enter accepts it.
